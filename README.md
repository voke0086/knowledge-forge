# 炼知引擎（Knowledge Forge）

> 把收藏夹里的素材，蒸馏成能调用的技能。

你的收藏夹有几百条干货，你的能力库为什么是空的？

因为「收藏」和「变成能力」之间隔着一道工序，而这道工序从来没人替你干完过。炼知引擎是一个可直接安装的 Agent Skill（SKILL.md 开放格式），装上之后，你的 AI 助手获得一条完整的知识蒸馏流水线：

```
任意素材（链接/图片/视频/音频/文档）
        ↓
九步流水线：全局理解 → 多视角提取 → 提炼 → 三重质量验证
        → 自动分类 → 检索关联 → 蒸馏成技能 → 压力测试
        → 独立评审 + 商业评估
        ↓
档案八件套 + 可复用、可出售的技能成品
```

## 它跟「让 AI 总结一下」有什么区别

两个设计是灵魂：

1. **三重质量验证**：AI 必须实际联网找 ≥2 个独立来源佐证（V1），必须证明方法能回答素材里没有的新问题（V2），必须剔除「要努力」式常识复读（V3）。三关不过，不配进你的知识库。
2. **禁止自评**：蒸馏知识的那个 AI，不许给自己的产物打分。必须由另一个上下文隔离的评审 agent 复核，作者滤镜被制度性消灭。

外加工程化细节：每笔产出带触发场景（没有触发条件的知识=存了等于没存）、流水线状态断点续跑、版本升级不删旧版、翻车点反向固化为铁律。

## 适合谁

- 重度 AI 用户：每天让 AI 读文章、看视频、做总结，但沉淀不下来的人
- 知识管理者：用 Obsidian / Notion 记笔记，想让 AI 按统一标准「消化投喂」的人
- 独立开发者 / 独立创作者：想把学到的工作流打包成可复用、甚至可出售的资产的人

## 安装

**Claude Code：**

```bash
git clone https://github.com/{你的用户名}/knowledge-forge.git
mkdir -p ~/.claude/skills/炼知引擎
cp knowledge-forge/SKILL.md ~/.claude/skills/炼知引擎/SKILL.md
```

**Claude 桌面端：** 设置 → Capabilities → Skills → 上传本技能文件夹。

**其他支持 SKILL.md 标准的客户端：** 把 SKILL.md 放进对应 skills 目录即可。

装好后对 AI 说：「投喂这个链接」「把这个视频做成技能」，引擎自动触发。

## 使用示例

- 丢一个视频链接：「消化一下」→ 档案八件套 + 一张带触发场景的精华卡
- 丢一篇教程：「提炼成技能」→ 过三重验证后蒸馏成 RIA++ 结构的 SKILL.md，直接装库复用
- 丢三篇同主题文章：「处理投喂」→ 自动去重、关联检索，融合升级成一个 v2 技能
