# 炼知引擎（Knowledge Forge）

> 普通 AI 记忆是原始数据的搬运工，炼知引擎是知识的炼金炉。
> 收藏是把原料堆进仓库，炼知引擎是把原料炼成金子——仓库越堆越乱，金子越攒越值钱。前者负责记住，后者负责变懂。

你的 AI 每天替你搬运原料，却从来没替你炼出过一块金子——差的不是料，是炉。

炼知引擎是一个可直接安装的 Agent Skill（SKILL.md 开放格式），装上之后，你的 AI 助手变成一座知识炼金炉：

```
任意矿料（链接/图片/视频/音频/文档）投炉
        ↓
九道炼序：验料通读 → 三镜辨矿 → 提炼精矿 → 三道验矿
        → 归仓分类 → 矿脉关联 → 熔铸成锭 → 串脉整合
        → 试金测试 → 出炉质检 + 金价评估
        ↓
档案八件套 + 可复用、可出售的金锭（技能成品）
```

## 它跟「让 AI 总结一下」有什么区别

两道工序是炉子的灵魂：

1. **三道验矿**：AI 必须实际联网找 ≥2 个独立来源佐证（V1），必须证明这块矿能回答素材里没有的新问题（V2），必须剔除「要努力」式常识废石（V3）。验不过的，直接进渣堆。
2. **出炉质检**：炼炉的师傅，不许验自己炼的金。必须由另一个上下文隔离的质检 agent 复核，火候不到就**回炉重炼**——作者滤镜在炉门口就被拦下。

外加工程化细节：每块金锭带触发场景（没有触发条件的知识=存了等于没存）、同主题散在≥3文件自动建专题整合文件（治知识各自为战）、流水线状态断点续跑、版本升级不删旧版、翻车点反向固化为铁律。

## 越喂越神（知识复利）

同一类知识，越喂越强：再喂同主题素材时，引擎不另起炉灶——认出同类，直接熔进旧版，坑点越补越全、版本号一路 +1（旧版归档不删，成长可溯）。夸张点说：一个领域一直喂下去，最后手里那块金锭，就是你在这个领域的神。

## 适合谁

- 重度 AI 用户：每天让 AI 读文章、看视频、做总结，但沉淀不下来的人
- 知识管理者：用 Obsidian / Notion 记笔记，想让 AI 按统一标准「消化投喂」的人
- 独立开发者 / 独立创作者：想把学到的工作流打包成可复用、甚至可出售的资产的人

## 安装

**Claude Code：**

```bash
git clone https://github.com/{你的用户名}/knowledge-forge.git
mkdir -p ~/.claude/skills/炼知引擎
cp knowledge-forge/SKILL.md ~/.claude/skills/炼知引擎/SKILL.md
```

**Claude 桌面端：** 设置 → Capabilities → Skills → 上传本技能文件夹。

**其他支持 SKILL.md 标准的客户端：** 把 SKILL.md 放进对应 skills 目录即可。

装好后对 AI 说：「投喂这个链接」「把这个视频做成技能」，引擎自动触发。

## 使用示例

- 丢一个视频链接：「消化一下」→ 档案八件套 + 一块带触发场景的金锭
- 丢一篇教程：「提炼成技能」→ 过三道验矿后熔铸成 RIA++ 结构的 SKILL.md，直接装库复用
- 丢三篇同主题文章：「处理投喂」→ 自动辨矿去重、矿脉关联，融合升级成 v2 金锭
